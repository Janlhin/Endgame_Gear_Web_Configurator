# 测试问题清单（给远程志愿者 / 自用回归）

> 用法：按你手上的型号跳到对应小节，逐条打勾。每条都写了**怎么测**、**什么算通过**、
> **不通过说明什么**——"不通过"也是有效结果，照实填比空着有价值。
>
> 配套：
>
> - 导出数据：页面上的「导出测试数据包 (.json)」（型号/PID/固件/接口集合/blob/日志一次带走）
> - 志愿者流程：[`docs/remote-beta-guide.md`](https://github.com/Janlhin/Endgame_Gear_Web_Configurator/blob/main/docs/remote-beta-guide.md)
> - XM1 差分实验：[`docs/xm1-diff-kit.md`](https://github.com/Janlhin/Endgame_Gear_Web_Configurator/blob/main/docs/xm1-diff-kit.md)
>
> ⚠️ 通用红线：**一次只改一个值**；改之前先让页面自动导出备份；
> 出现"回读不一致"就**停下来**，不要重试。

## 零、环境与连接（所有型号都要过一遍）

- [ ] 浏览器与版本？（Chrome / Edge 都可，Firefox / Safari 没有 WebHID，连不上是正常的）
- [ ] 页面顶部有没有报"此环境没有 WebHID"？有就换浏览器，不用往下测了
- [ ] 点"连接"后列出的设备里，能不能看到你的鼠标/接收器？把设备名抄下来
- [ ] 连上后**鼠标指针还能正常移动吗**？（不能 = 选错了接口，立刻关掉标签页即可恢复，请告诉我）
- [ ] 页面显示的型号名对不对？不对请把实际型号和页面显示的一起发来
- [ ] 固件版本有没有读出来？读出来是什么（形如 `1.37`）？官方工具里显示的是什么？
- [ ] 电量读数（无线）合理吗？和实际感觉差多少？
- [ ] 点「导出测试数据包」，文件能正常生成吗？（先存好，后面每一步都能用上）
- [ ] **连续点两次「重新读取」，导出的两份数据包里的 blob 完全一样吗？**
      （不一样的字节位置：______________________）
      ⚠️ 这是我们做"差分定位"的前提：如果某些字节每次都在变，它们就不能用来找字段。
      两次一致 → 请把第二份也发来，这份空白数据对我们很值钱

## 一、8k 有线全系（XM2 8k / OP1 8k / Purple Frost / 两个 v2）—— 最需要的一档

> 这一档我们的协议是"官方二进制 + 四个社区实现"交叉印证出来的，**但从来没上过真机**。
> 写入默认关闭，点一次会弹确认——确认后只在你这次连接里有效。

**读取是否正确**

- [ ] 连接后能读出配置吗？（日志里应有 `✓ 8k blob read OK`）
- [ ] 页面解析出的 **CPI 四档**和你在官方工具里设的值一致吗？逐个对照写出来
- [ ] 解析出的**回报率**对吗？（8000 / 4000 / 2000 / 1000 Hz）
- [ ] 解析出的 **LOD** 对吗？（v1 是 0.7 / 1 / 2 mm；v2 是 0.7–1.7 mm）
- [ ] Angle Snap / Ripple / Motion Sync 三个开关的状态和官方工具一致吗？

**写入是否有效**（每改一项就记一次）

- [ ] 只改 **CPI 第 1 档**（如 800 → 1600）→ 页面提示"回读校验通过"吗？
- [ ] ⭐ **实际手感/速度变了吗？是 1:1 的变化，还是明显差了一个数量级？**
      （差一个数量级 = 我们的 CPI 编码理解错了，这条最重要）
- [ ] 改**回报率** → 回读通过吗？用官方工具确认真的变了吗？
- [ ] 改 **LOD** → 回读通过吗？抬离高度手感有变化吗？
- [ ] 切换 **Angle Snap / Ripple / Motion Sync** → 回读通过吗？
- [ ] 你的型号支持**玻璃模式**吗（v2 与 Purple Frost 才有）？切一下有反应吗？
- [ ] 按"恢复出厂"能用吗？（**不可撤销**，放最后做）

**按键（我们最没底的一块）**

- [ ] 页面读出的按键映射和你实际设的一致吗？（我们按"7 条 × 7 字节、起点 blob 0x3D"解析）
- [ ] 如果官方工具里改了一个按键映射，页面重新读取后能看到变化吗？

## 二、WE 族（XM2we）—— ✅ 已闭环（2026-11-04），只剩 OP1we 待测

> 这一族已由一位 XM2we 用户在真机上走完（issue #1）：读取（有线 `0x1960` + 无线 `0x1961`）、
> 写入（两种连接）、LOD 映射、CPI / 回报率 / 去抖，全部与官方工具逐项吻合。
> 下面保留**已确认的结论**与**仍空着的部分**，供持 OP1we 的人接手。

### 已确认，不必重复

- 读取：181 字节（`0x00–0xB4`），单帧最多 10 字节、约 19 个来回；**有线与无线读出的内容逐字节一致**
- 写入：单档 CPI 切换**即时生效**、无需重启鼠标；恢复后 181 字节与原始备份**完全一致**
- 字段位置：`0x02` 启用档数 / `0x04` 当前生效档（**0 基**）/ `0x0A` LOD（1=1mm、2=2mm）/ `0xA9` 去抖
- 未变化的字段**不会再被重写**（日志会显示「没有字段发生变化」）
- 界面上的「生效中」按 `0x04` 标注，不再硬编码在槽 1

### 仍需测（持 OP1we 的人）

- [ ] OP1we 能否连上？（有线 `0x1962` / 接收器 `0x1961`）
- [ ] 能读出 181 字节吗？与 XM2we 的字段位置是否一致？
- [ ] 单档 CPI 写入 → 回读一致吗？官方工具是否同步显示？

### 仍未确认（不影响使用，属已知未知）

- `0xAD` 休眠值的单位（厂商工具显示 raw × 10），因此界面上**只读展示、不提供写入**

## 七、判读速查（看到现象 → 大概是什么原因）

| 现象 | 多半是 |
|---|---|
| 回读不一致，且差值是整数倍（×2、×10） | CPI / 步进编码理解错 |
| 回读一致但手感没变 | 偏移对、语义错（写到了别的字段） |
| 完全读不出来 | 接口集合选错，或族判错（看日志里的 usage page） |
| 无线下超时、有线正常 | 鼠标休眠 / 唤醒时序不够 |
| 页面卡住、鼠标动不了 | 误开指针接口（关标签页即恢复） |
