# 面向用户的设置清单（从"鼠标用户"而不是"协议"出发）

> 2026-10-09 整理。目的：在**协议能做什么**之上，回答**用户到底想要什么设置**。
> 每一项都标注了依赖与风险，避免把"做得到"当成"值得做"。

## 〇、先把一个诚实的判断放前面

对 **XM2w 4k v2**（你手上的主力）来说，官方工具**已经有**大部分旋钮：CPI 四档、
按键映射、回报率、Motion Sync、Slamclick、抖动过滤、省电/深度休眠、电池与固件版本。

**所以"能加什么设置"这件事，真正的空白不是旋钮数量，而是这三件：**

1. **没人告诉你那个滑杆是什么** —— 官方 Advanced 页的 Angle Snap / Angle Tune /
   Smoothing 全是**没有任何说明**的滑杆，用户根本不知道该不该动
2. **改乱了回不去** —— 没有历史版本、没有自动备份、没有"回到刚才那份"
3. **换设备/重装系统就得重调** —— 配置搬不走、也没法给别人

加上平台层面：官方是 Windows 安装器，macOS / Linux 用户**根本没有官方选项**。

---

## 一、把"看不懂"变成"能理解"（最高性价比，零协议风险）

| 想法 | 具体做法 | 依赖 |
|---|---|---|
| **每个设置一句人话** | 滑杆/选项旁一个 `?`：这个值是什么、什么情况下该改、改了会怎样 | 无 |
| **把滑杆换成能理解的选项** | "Lift Cut-Off" 直接显示 `2.0 mm`（而不是原始值 `0x06`）；Ripple 显示"开/关 + 一句话" | XM1 已确证编码；4k 待补 |
| **预设（按用途）** | 一键套用：FPS / MOBA / 桌面办公 / 绘图。每组是一套 CPI + LOD + Ripple + 回报率说明 | 无（纯前端） |
| **每档 CPI 备注** | "CS 用 400""桌面 1600"，比只给 LED 颜色有用得多 | 无 |

> 这一类的价值来自**信息**，不是协议能力 —— 也是我最想先做的。

## 二、让"改坏了"不可能（信任建设，也是我们欠的）

| 想法 | 具体做法 | 依赖 |
|---|---|---|
| **写入前自动备份** | 每次下发写入前，先把当前 1024B 存一份（内存 + 可下载） | 无 |
| **快照时间线 + 一键回退** | 列出"今天 01:12 / 01:18 / 01:24"几份快照，点一下回到某一份 | 无 |
| **只读锁** | 连接后默认只读，写入需要显式解锁；断开即恢复只读 | 无（已有类似机制） |
| **改前 diff 预览** | 应用前显示"将要改动这 6 个字节"，确认后才发 | 已有（工具页的 diff 原型） |

> 出事之后，**"我能随时退回去"比"功能多"重要得多**。

## 三、配置能带走、能给出去

| 想法 | 具体做法 | 依赖 |
|---|---|---|
| **可读 JSON 导入导出** | 已有。含字段名 + hex，可进版本库 | ✅ 已实现 |
| **分享码 / 链接** | 生成一小段文本（例如 `EGG-XM1:800,1600,3200,6400;LOD2;RIP1`），别人粘进去就套用 | 无（分享链接需后端） |
| **多设备管理** | 你有 XM1 + XM2w 4k v2：分别保存，一键互套 | 无 |
| **导入时校验** | 导入别人配置时先做一次范围/合法性检查，避免写入非法值 | 无 |

## 四、手感本身还能加什么

| 想法 | 说明 | 依赖 |
|---|---|---|
| **XY 独立 CPI** | **官方没有**：官方每档只有一个输入框（X=Y），而 4k 族协议里有 XY 使能字节 | ✅ **4k 族已真机验证通过**（2026-10-09，XM2w 4k v2 上手感明显不同）；**XM1 不支持**（固件只读 X，实测改 Y 无效） |
| **档位数量 1–4 可裁** | 只用两档就关掉其余，避免误触；已有控件，可强化联动禁用 | 已部分实现 |
| **一键复制某档到其它档** | 调好一档后套到其余几档 | 无 |
| **CPI 步进提示/校验** | 官方 CPI 有步进限制（1234 被拒，1150 可）；前端先校验并提示合法值 | 已踩过这个坑 |
| **Angle Snap / Angle Tune / Smoothing** | 官方有滑杆但我们**尚未定位**它们在 blob 里的位置 | ⏳ 需差分 |
| **灯效（每档 LED、3 个区域）** | 官方 XM1 工具有 `CPI1 LED1..4 … CPI4 LED1..4` 共 16 个控件；我们未定位偏移 | ⏳ 需差分 |
| **回报率** | XM1 是**底部硬件拨动开关**，软件改不了；4k 族协议里是枚举，可实现但未真机验证 | ⛔ / ⏳ |

## 五、官方完全没有的（平台层）

- **macOS / Linux**：官方只有 Windows 安装器，网页版天然跨平台
- **免安装 / 免管理员**：官方要装驱动组件
- **开源可审计**：官网分发的工具曾被植入 XRed 木马，源码可读是直接对冲
- **无障碍**：全键盘可操作、屏幕阅读器标注、高对比
- **命令行 / 脚本化**：进阶用户批量套配置

## 六、明确**不该加**的（用户视角的坑）

| 不做 | 原因 |
|---|---|
| 回报率（XM1） | 硬件开关，做不出来 |
| 固件升级 | `.fub` 加密，刷坏进 bootloader（两 LED 红闪），砖了不赔 |
| 宏编辑 | 存储格式未知；且宏的兼容性坑很深 |
| "解锁未公开功能"（改传感器寄存器、拉高 DPI 上限等） | 超规格使用，可能造成不可逆问题，而且不属于"配置" |
| 云端自动同步配置（未经同意） | 配置是个人数据，默认本地 |

## 七、我的优先级建议

1. **一（把看不懂变成能理解）** —— 零风险、立刻可感知；尤其"每个设置一句人话"
2. **二（改坏了不可能）** —— 写入解锁前必须先有这层
3. **三（配置能带走）** —— 分享码 + 多设备，纯前端
4. **四里只做已确证的**：XY 独立（**4k 已真机验证**，XM1 不支持）、档位裁剪、复制档位
5. **四里未知的（Angle/Smoothing/灯效）** 逐个差分定位后再做，不猜

> 一句话：**先做"看得懂、退得回、带得走"，再谈多几个滑杆。**
