# 网页版 vs 官方原版：差异清单

> 对照基准：官方 **XM1 Configuration Software v1.09** 与
> **XM2w 4k v2 Configuration Tool v1.02**（用户手上两套）。
> 原则：**没有证据支撑的不写进来**；分四类 —— ✅ 已验证可用 / ⚠️ 已实现待验证 /
> 🔬 待研究 / ❌ 不做。写入类功能一律以"协议已核实"为前提。
> 最后更新 2026-10-09。

## 一、官方原版是什么（对照基准）

| | XM1 v1.09 | XM2w 4k v2 v1.02 |
|---|---|---|
| 形态 | Windows `.exe` 安装器 | Windows `.exe` 安装器 |
| 语言 | 仅英文 | 仅英文 |
| 主题 | 仅浅色 | 仅浅色 |
| 配置备份 | 自有格式（Import / Delete / Reset） | 自有格式（Import / Delete / Reset） |
| 功能 | CPI（4 档单值）、按键映射、Advanced（Angle Snap/Tune、LOD、Polling Rate、Smoothing、Surface Calibrate）、Lights、配置档（最多 5 个，存 PC 侧文件） | 传感器/CPI、性能/电源、按键映射、配对、恢复出厂 |
| 备注 | — | LED 页签与 Surface Calibration 在 v1.02 中**未发现协议实现路径**（共用 OEM 模板遗留） |

## 二、网页版多出来的

### ✅ 已实现且可用

| # | 项 | 官方 | 网页版 |
|---|---|---|---|
| 1 | **运行方式** | Windows 安装器，需管理员权限 | **单个 HTML**，Chrome / Edge 直接打开；**零安装、免管理员、跨平台**（macOS / Linux 同样可用） |
| 2 | **源码可审计** | 闭源二进制 | 全部开源。**动机不是空谈**：2025-06/07 官网分发的 OP1w 4k v2 工具曾被植入 **XRed 木马** |
| 3 | **配置备份格式** | 自有格式，无法阅读或进版本库 | **可读 JSON**（字段名 + `blobHex` + `blobB64` + 设备/时间）+ **原始 1024B `.bin`** |
| 4 | **通讯日志** | 无 | **hex 级报文日志**（可折叠），排障与逆向都靠它 |
| 5 | **写入后回读校验** | 无 | XM1 ✅、XM2we ✅：写完自动读回，逐项比对并列出不一致项 |
| 6 | **改错可回退** | 无 | XM1：写入前**逐字节差异预览**确认 + **快照（最多 20 份）一键回退** |
| 7 | **语言** | 仅英文 | 8 种：简中 / 繁中 / 英 / 德 / 法 / 西 / 日 / 韩；**首次打开按浏览器语言自动选择**，之后手动选择的偏好存 localStorage 并优先；日韩繁体自动切 CJK 字体栈 |
| 8 | **主题** | 仅浅色 | 浅色 / 深色（跟随系统，无刷新闪烁） |
| 9 | **离线分析工具** | 无 | `tools/blob-studio.html`：粘 hex 或导出的 JSON 即可解析成字段表；**粘两份自动做字段级差分**（本项目定位偏移用的就是这套方法） |
| 10 | **XM1 字段编辑** | 有，但仅单值 CPI | 单值 CPI、Lift Cut-Off、Ripple —— 写入**硬限制在 23 个实测确认的字节**内，其余字节必须与读回值逐字节相同 |
| 11 | **XY 独立 CPI**（★ 官方没有） | 每档**一个**输入框（X = Y） | 每档 **XY 开关 + 独立 X / Y 输入框**。协议里每档是 `0x23+5n` 的 5 字节 `[XY使能][X][Y]`，读/写/UI 三处完整实现。**2026-10-09 在 XM2w 4k v2 上真机验证：手感明显不同 → 真实生效**。XM1 不支持（协议里没有该字段） |

| 项 | 说明 |
|---|---|
| ~~4k 族的写入后回读校验~~ | ✅ **2026-10-09 已完成** —— `snapSensor/verifySensor`、`snapPerf/verifyPerf`、`snapButtons/verifyButtons` + `reportVerify()`，覆盖 `applySensor` / `applyPerf` / 导入三条路径 |

## 三、官方有、网页版还没有

| 项 | 现状 |
|---|---|
| **固件升级** | 官方另有 `Firmware Update Tool`。`.fub` 载荷加密，且刷坏会进 bootloader（两 LED 红闪）—— 见"不做" |
| **灯效（XM1 Lights 页）** | 官方 XM1 工具确有该页（Mode/Speed/Strength + WHEEL/LOGO/BOTTOM LED + COLOR）；对应 blob 偏移**尚未定位**，差分即可得 |
| **Surface Calibration** | 官方 v1.02 中未发现协议实现路径；XM1 工具模板里有控件 |
| **宏** | 存储位置与编码格式未确认（可能在 PC 侧文件） |
| **多配置档保存（XM1）** | 官方支持最多 5 个 profile（存 PC 侧 `.profile`/`pfList.dat`）；未逆向其文件格式 |

## 四、做不了 / 不做

| 项 | 原因 |
|---|---|
| **回报率（XM1）** | **鼠标底部 3 档硬件拨动开关**（250/500/1000 Hz），由 GPIO 读取 —— **软件改不了，官方也改不了**（`re/XM1_NOTES.md` 6.11 节） |
| **回报率（4k 族）** | 协议里是枚举写入，**可实现**，但未真机验证，需受控写入测试 |
| **固件升级** | 载荷加密 + 刷坏进 bootloader，风险与收益不成比例 |
| **宏编辑** | 存储与编码未定 |
| **任何未验证的写入路径** | 2026-10-09 已付代价：发送未核实形态的 1041B 报文把鼠标 DPI/CPI 清零。**未核实即不发**是硬红线 |

## 附：一句话总结

官方工具是"**Windows 安装版，只做配置**"；本网页版是
"**浏览器即开，配置 + 可审计 + 可备份对比 + 可回退**"，
但在**功能覆盖度**上仍不如官方（缺固件升级、XM1 灯效、多配置档）。
差异化价值集中在**可审计、可回退、可带走的配置**，而不是"功能更多"。
