## 零、准备

- 网页工具：`index.html`（双击用 Chrome/Edge 打开，走 WebHID，**不能在内置预览面板里**）。
- 官方软件：XM1 Configuration Software v1.09（已装）。
- 差分脚本：`re/archive/xm1_diff.py`（Python 3，只读分析，不碰设备）。
- 备选：离线分析器 `tools/blob-studio.html` —— 粘两份 hex 自动差分，不用连设备。

## 一、通用流程（每个实验都一样，只改「改哪一项」）

1. 打开网页工具 → 连接 XM1 → 等读取完成。
2. 点 **「导出原始 1024B blob (.bin)」** → 存为 `xm1_base.bin`（放到 `re/` 下）。
3. **关闭网页工具的占用**（直接在另一个窗口打开官方软件；若官方报"设备被占用"，
   就先关掉网页标签页）。
4. 官方软件里 **只改一个值** → 应用/保存 → 关闭官方软件。
5. 回到网页工具 → 刷新（或重新连接）→ 再导出 → 存为 `xm1_<实验名>.bin`。
6. 跑差分：

   ```bash
   python re/archive/xm1_diff.py re/xm1_base.bin re/xm1_<实验名>.bin
   ```

7. 把输出**整段贴回会话**。脚本会标注哪些偏移是"已知可写"、哪些是"新候选"。

⚠️ 三条纪律：

- **一次只改一个值**。改两项就分不出哪个字节对应哪个。
- 每个实验**独立跑一遍**（不要在上一个实验的结果上继续改），否则差异会叠加。
- 若输出是"两份完全一致"，说明这个改动**不落在 blob 里**（写在别的通道或根本没保存），
  这本身也是结论，请照样贴回。

## 二、四个实验

### 实验 1 · 灯效（Lights 页）

官方 Lights 页逐项改，**每项单独存一份**：

| 子实验 | 改动 | 存为 |
|---|---|---|
| 1a | Mode（模式）换一个 | `xm1_led_mode.bin` |
| 1b | Speed（速度）改一档 | `xm1_led_speed.bin` |
| 1c | Strength（亮度）改一档 | `xm1_led_strength.bin` |
| 1d | 第一组 LED 的颜色改成明显不同的值 | `xm1_led_c1.bin` |
| 1e | LED ON → OFF（或反之） | `xm1_led_on.bin` |

> 线索：4k 族里 `blob[15..34]` 是 4 档 LED 颜色 `[R][G][B][enabled][id]`；
> XM1 的 blob 在 `0x05B–0x05F` 之后仍有大片零区，灯效很可能落在其后。

### 实验 2 · 按键映射（Buttons 页）

只把 **左键** 改成另一个功能（例如改成"中键"或"键盘某键"）→ 存 `xm1_btn_left.bin`。
再单独把**侧键**改一次 → `xm1_btn_side.bin`。

> 线索：候选区是 `0x0C7 + 5n` 的 7 项表（每项 5 字节）。
> 已知：`0x06C–0x08F` 那片像 5 字节步长结构（`0f 00 02 00 00` / `0f 00 04 00 00` …），
> 值 `0x02/0x04/0x08/0x10` 正是鼠标键位掩码 —— **极可能就是按键表**，只差一次差分确认。

### 实验 3 · Angle Snap / Smoothing / Angle Tune（Advanced 页）

逐项单改：Angle Snap 开→关（`xm1_angle.bin`）、Smoothing 改一档（`xm1_smooth.bin`）、
若有 Angle Tune 则改一次（`xm1_tune.bin`）。

### 实验 4 · 单字节通道语义

不改任何设置，只做物理动作：

| 子实验 | 动作 | 存为 |
|---|---|---|
| 4a | 拨动鼠标底部开关（回报率 250/500/1000），拨一次读一次 | `xm1_sw1.bin` / `xm1_sw2.bin` |
| 4b | 按下鼠标底部按键（如果有），前后各读一次 | `xm1_bottombtn.bin` |

> 说明：已知回报率是**硬件开关**，blob 里不变（实测确认过）；
> 这个实验要找的是 `blob[0]` 那个字节的含义 —— 它是 `buf[5]` 与 `cmd 0x04` 的来源，
> 在未搞清前**本工具绝不写它**。
