本型号属 2020 年有线/2.4G 协议族（接口页 0xFF02、报告 0x08/0x09、17 字节带校验帧、配置存于 EEPROM），与 4k 无线族完全不兼容。

CPI 与回报率

档位CPI XCPI YLED 颜色校验

槽位 1 是当前生效的 CPI，写入即刻改变指针速度，无需保存或断电。鼠标上的按钮切换的是回报率而非 CPI 档位——它的闪烁次数很容易被误读成档位。

存放为 one-hot 掩码：0x08=125 / 0x04=250 / 0x02=500 / 0x01=1000 Hz

按键矩阵（EEPROM 0x60）

按键映射type / code / param校验

本族仅 type 0x01（鼠标键位掩码：0x01 左 / 0x02 右 / 0x04 中 / 0x08 后退 / 0x10 前进）被社区解出；其余类型语义未知，工具原样读取展示，不做改写。

EEPROM 备份 / 恢复

配置区为 EEPROM 0x00–0xB4（共 181 字节），每帧最多带 10 字节，故读取需约 19 个来回；每条记录都带 0x55 补码校验，校验只保证记录边界正确、不代表字段语义已解出。写入一律回读验证。

说明与已知限制
  • 需要 Chrome / Edge 89+（WebHID）。本页通过 HID 特征报告直连设备，不装任何驱动。
  • ⚠ 若连接后鼠标突然失灵：立刻关闭本页面/浏览器窗口即可恢复（WebHID 会独占所选接口，关闭即释放；插拔 USB 无效）。本页只打开厂商定义接口，不会碰鼠标指针接口。
  • 支持全部四个无线型号：XM2w 4k / XM2w 4k v2 / OP1w 4k / OP1w 4k v2，有线（USB-C）与无线（4k 接收器）均可。型号由 cmd 0x0E 返回的鼠标 PID 自动识别。
  • 有线专用型号（XM2we、XM1 系列等）使用另一套未公开协议，暂不支持。
  • 鼠标深度休眠后读不到配置：动一下鼠标再点“重新读取”。软件会自动发探测命令恢复通道。
  • 有线连接时 0x0D（接收器固件）会返回“不适用”；有线回报率硬件上限 1000 Hz。
  • v1 的“当前档位”只能用鼠标底部的 CPI 键切换，软件改了也无效（硬件忽略）。
  • 协议已对照官方 v1.02 配置工具二进制逐字节验证：命令表、负载长度、blob 布局、双块写入与重试时序全部一致；0x71/0x72（默认配对/配对数据）为官方工具新增命令，本页已同步实现。
