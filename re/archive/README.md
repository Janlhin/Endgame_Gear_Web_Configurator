# re/ 归档：逆向探查脚本

## 为什么归档而不是删除

这些脚本是对**官方 Windows 客户端二进制**做逆向分析的探查工具。
它们的价值不在代码本身，而在于**可复现的证据链**——协议文档里的每个结论
都标注了「用哪个脚本、扫哪个 RVA 区间得到的」。删掉它们，
那些结论就退化成「某人某天看到的」，无法被第二个人复核。

判例四亦已授权：**逐个评估后归档，不删除**（2026-10-09用户裁决）。

## 归档清单与用途

| 脚本 | 用途 | 产出沉淀在 |
|---|---|---|
| `dias.py` | 反汇编指定 RVA 区域 | `PROTOCOL_NOTES.md`、`XM1_NOTES.md` |
| `obj_scan.py` | 找 `.text` 中引用指定地址（immediate）的位置 | 同上 |
| `obj_scan2.py` | 扫 `0x5866B0..0x586740` 区间的全部指令 | 同上 |
| `cmd_scan.py` | 扫 `mov dword ptr, 0xA1XX`（reportId+cmd 一次写入） | 同上 |
| `const_scan.py` | 全镜像搜 16/32 位立即数（找协议常量） | 同上 |
| `imm_scan.py` | 扫引用指定地址的指令位置 | 同上 |
| `xref_scan.py` | 扫 `call`/`jmp` 到 hidapi 函数的全部位置 | 同上 |
| `reportid_scan.py` | 搜 `.text` 中写 0xA1 / 0xA0 报告 ID 的指令 | 同上 |
| `xm1_blob_analysis.py` | 分析 XM1 真机 blob（2026-10-09 实测） | `XM1_NOTES.md` |
| `xm1_blob_struct.py` | 同上（结构视角） | 同上 |
| `xm1_diff.py` | 多次 blob 差分，找变化字节＝字段偏移 | `XM1_NOTES.md` 6.7 节 |

## 依赖

全部针对 `re/upstream/` 下的官方二进制（已 gitignore，不入库）。
运行前需要先有那份二进制——具体获取方式见 `SOURCES.md`。

## 什么时候该动它们

**不要删。** 若将来要重做某段逆向，直接从这里取用即可——
它们的输入输出都很小（读一个 .text、打印偏移表）。

若确认某个脚本的结论已彻底沉淀、且不会再有人复核，
可在本文档里标注「已废弃」并写明替代手段——**但仍不删文件**。
